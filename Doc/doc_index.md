# Documentation Index - F3 Speedometer Mod

## Overview
F3 Speedometer is a zero-dependency client mod for Minecraft 26.2 that integrates a real-time movement velocity indicator directly into the F3 debug screen ecosystem (`DebugScreenEntries`).
