# プレイヤーガイド - スピードメーター (Speedometer)

## クイックスタート (Quick Start)
1. Fabric Loader を導入します。
2. `speedometer-1.2.9+<version>.jar` を `.minecraft/mods` フォルダに配置します。
3. Minecraft を起動し、**`F3`** (または **`F3 + F6`**) を押してスピードメーターの表示を確認します。

---

## F3 設定メニューの切り替え (`F3 + F6`)
ゲーム内で **`F3 + F6`** を押すと、デバッグオプションメニュー (Debug Options Screen) が開きます。お好みのレイアウトを選択できます：

1. **両方のオプションを有効化** (スマートな1行統合表示)：
   `Speed: 0.215 blocks/tick, 4.30 b/s (H: 4.30, V: 0.00)`
2. **`speedometer` のみ有効化 (スピードメーター)**：
   `Speed: 4.30 b/s (H: 4.30, V: 0.00)`
3. **`player_speed` のみ有効化 (バニラ)**：
   `Speed: 0.215 blocks/tick`

---

## 速度表示の数値解説
- **Speed (総合速度)**: 3次元空間における実際の移動速度（ブロック/秒、b/s）。
- **H (Horizontal / 水平速度)**: X/Z 平面上の地上・乗り物移動速度（歩行、ダッシュ、乗馬、トロッコ、ボート）。
- **V (Vertical / 垂直速度)**: Y 軸方向の上下移動速度（ジャンプ、落下、はしご昇降、エリトラ滑空・上昇）。

---

## 常時 HUD 表示モード (Always-Active HUD)
- **`F3 + F6`** を押してデバッグオプションを開きます。
- **スピードメーター (speedometer)** の項目を見つけ、状態を **`Always` (常時表示)** に変更します。
- ゲーム画面に戻ると、F3 画面全体を展開することなく、軽量な HUD として速度計を常時画面に表示できます！
