# 플레이어 가이드 - 속도계 (Speedometer)

## 빠른 시작 (Quick Start)
1. Fabric Loader를 설치합니다.
2. `speedometer-1.2.12+<버전>.jar` 파일을 `.minecraft/mods` 폴더에 넣습니다.
3. 마인크래프트를 실행하고 **`F3`** (또는 **`F3 + F6`**)를 눌러 속도계 표시를 확인합니다.

---

## F3 설정 메뉴 변경 (`F3 + F6`)
게임 내에서 **`F3 + F6`**를 눌러 디버그 옵션 화면(Debug Options Screen)을 엽니다. 원하는 속도 표시 레이아웃을 선택할 수 있습니다:

1. **두 옵션 모두 활성화** (스마트 단일 행 통합 표시):
   `Speed: 0.215 blocks/tick, 4.30 b/s (H: 4.30, V: 0.00)`
2. **`speedometer`만 활성화 (속도계)**:
   `Speed: 4.30 b/s (H: 4.30, V: 0.00)`
3. **`player_speed`만 활성화 (바닐라)**:
   `Speed: 0.215 blocks/tick`

---

## 속도 표시 수치 이해
- **Speed (종합 속도)**: 3차원 공간 내 플레이어의 실제 이동 속도 (초당 블록 수, b/s).
- **H (Horizontal / 수평 속도)**: X/Z 평면 지상/탈것 이동 속도 (걷기, 달리기, 승마, 마인카트, 보트).
- **V (Vertical / 수직 속도)**: Y축 상하 이동 속도 (점프, 낙하, 사다리, 겉날개 활공).

---

## 상시 HUD 모드 (Always-Active HUD)
- **`F3 + F6`**를 눌러 F3 디버그 옵션을 엽니다.
- **속도계 (speedometer)** 항목을 찾아 상태를 **`Always` (항상 표시)**로 변경합니다.
- 게임으로 돌아오면 복잡한 F3 디버그 화면을 펼치지 않고도 깔끔한 경량 HUD로 속도를 상시 확인할 수 있습니다!
