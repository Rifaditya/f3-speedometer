# Руководство игрока - Спидометр (Speedometer)

## Быстрый старт (Quick Start)
1. Установите Fabric Loader.
2. Поместите файл `speedometer-1.2.5+<версия>.jar` в папку `.minecraft/mods`.
3. Запустите Minecraft, нажмите **`F3`** (или **`F3 + F6`**), чтобы увидеть показатели скорости.

---

## Настройка оверлея F3 (`F3 + F6`)
В игре нажмите **`F3 + F6`**, чтобы открыть меню настроек экрана отладки (Debug Options Screen). Вы можете выбрать удобный режим отображения:

1. **Включены обе опции** (умное совмещение в одну строку):
   `Speed: 0.215 blocks/tick, 4.30 b/s (H: 4.30, V: 0.00)`
2. **Включен только `speedometer` (спидометр)**:
   `Speed: 4.30 b/s (H: 4.30, V: 0.00)`
3. **Включен только `player_speed` (ванильный)**:
   `Speed: 0.215 blocks/tick`

---

## Пояснение значений спидометра
- **Speed (Общая скорость)**: Фактическая скорость перемещения игрока в 3D пространстве в блоках в секунду (б/с).
- **H (Horizontal / Горизонтальная скорость)**: Скорость по осям X/Z на плоскости (ходьба, бег, верховая езда, вагонетки, лодки).
- **V (Vertical / Вертикальная скорость)**: Скорость перемещения по оси Y (прыжки, падение, подъем по лестницам, полет на элитрах).

---

## Постоянный HUD оверлей (Always-Active HUD)
- Нажмите **`F3 + F6`**, чтобы открыть меню настроек F3.
- Найдите пункт **Спидометр (speedometer)** и переключите статус на **`Always` (Всегда)**.
- Вернитесь в игру: спидометр останется на экране без необходимости держать открытым весь экран отладки F3!
