# Guide du Joueur - Compteur de Vitesse (Speedometer)

## Démarrage Rapide (Quick Start)
1. Installez Fabric Loader.
2. Placez le fichier `speedometer-1.2.11+<version>.jar` dans votre dossier `.minecraft/mods`.
3. Lancez Minecraft, appuyez sur **`F3`** (ou **`F3 + F6`**) pour afficher la ligne de vitesse.

---

## Configuration du Menu F3 (`F3 + F6`)
Dans le jeu, appuyez sur **`F3 + F6`** pour ouvrir l'écran des options de débogage (Debug Options Screen). Vous pouvez personnaliser la disposition d'affichage :

1. **Les deux options activées** (Fusion intelligente sur une seule ligne) :
   `Speed: 0.215 blocks/tick, 4.30 b/s (H: 4.30, V: 0.00)`
2. **Seul `speedometer` activé (Compteur de vitesse)** :
   `Speed: 4.30 b/s (H: 4.30, V: 0.00)`
3. **Seul `player_speed` activé (Vanilla)** :
   `Speed: 0.215 blocks/tick`

---

## Comprendre les Valeurs de Vitesse
- **Speed (Vitesse totale)** : Vitesse de déplacement tridimensionnelle réelle en blocs par seconde (b/s).
- **H (Horizontal)** : Vitesse sur le plan X/Z au sol (marche, course, cheval, wagonnet, bateau).
- **V (Vertical)** : Vitesse sur l'axe Y (sauts, chutes, échelles, vol en élytres).

---

## Mode HUD Permanent (Always-Active HUD)
- Appuyez sur **`F3 + F6`** pour ouvrir les options F3.
- Recherchez **Compteur de vitesse (speedometer)** et changez son statut sur **`Always` (Toujours)**.
- Retournez en jeu : le compteur de vitesse restera affiché comme un HUD léger sans avoir besoin d'ouvrir tout l'écran F3 !
