# Panduan Pemain - Spidometer (Speedometer)

## Mulai Cepat (Quick Start)
1. Pasang Fabric Loader.
2. Tempatkan berkas `speedometer-1.2.10+<versi>.jar` di dalam folder `.minecraft/mods`.
3. Buka Minecraft, tekan **`F3`** (atau **`F3 + F6`**) untuk melihat tampilan spidometer.

---

## Mengatur Tata Letak Menu F3 (`F3 + F6`)
Di dalam game, tekan **`F3 + F6`** untuk membuka menu opsi debug (Debug Options Screen). Anda dapat memilih mode tata letak kecepatan yang diinginkan:

1. **Kedua opsi diaktifkan** (Penggabungan 1 baris pintar):
   `Speed: 0.215 blocks/tick, 4.30 b/s (H: 4.30, V: 0.00)`
2. **Hanya `speedometer` diaktifkan (Spidometer)**:
   `Speed: 4.30 b/s (H: 4.30, V: 0.00)`
3. **Hanya `player_speed` diaktifkan (Vanilla)**:
   `Speed: 0.215 blocks/tick`

---

## Memahami Nilai Tampilan Kecepatan
- **Speed (Kecepatan Total)**: Kecepatan pergerakan 3 dimensi sebenarnya dalam blok per detik (b/s).
- **H (Horizontal)**: Kecepatan pada bidang datar X/Z (berjalan, berlari, menunggang kuda, kereta tambang, perahu).
- **V (Vertikal)**: Kecepatan pada sumbu Y (melompat, jatuh, menaiki tangga, meluncur dengan elytra).

---

## Mode HUD Selalu Aktif (Always-Active HUD)
- Tekan **`F3 + F6`** untuk membuka opsi F3.
- Temukan opsi **Spidometer (speedometer)** dan ubah statusnya menjadi **`Always` (Selalu)**.
- Kembali ke permainan: spidometer akan tetap tampil di layar sebagai HUD ringan dan bersih tanpa perlu membuka layar F3 penuh!
